# AutoHub - Vehicle Service & Sales Platform


AutoHub is a comprehensive web platform for vehicle services, sales, and maintenance management. The system includes user authentication, service tracking, and vehicle sales features.

## ✨ Key Features

### 🔐 User Authentication
- Secure login/signup system
- Password reset functionality
- Session management

### 🚗 Vehicle Services
- Service appointment booking
- Breakdown assistance request
- Service history tracking

### 💰 Vehicle Sales
- Platform for selling vehicles
- Vehicle listing management
- Buyer-seller communication

### 📱 Responsive Design
- Mobile-friendly interface
- Smooth scrolling navigation
- Interactive elements

## 🛠️ Technologies Used

### Frontend
- HTML5, CSS3, JavaScript
- Responsive design with Flexbox/Grid
- Ion Icons for vector icons

### Backend
- PHP for server-side processing
- MySQL database
- RESTful API design

### Additional Tools
- Git for version control
- Visual Studio Code as IDE
- Chrome Developer Tools

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/Hasith819/AutoHub-Web-App.git

2. Set up the database:

Import fastshift.sql to your MySQL server

Update connection details in connection.php

3. Configure the server:

Place files in your web server directory (e.g., htdocs or www)

Ensure PHP and MySQL are properly installed

4. Access the application:
